# Security policy

Activity Log stores personal schedules locally and imports data from files and links that
anyone can create, so import validation and data isolation matter.

Please report vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/Etherdancer/activity-log-pwa/security/advisories/new)
instead of a public issue.

Only the latest version deployed at https://activity-log-pwa.pages.dev/ is supported.
